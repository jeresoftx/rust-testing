# Costos y benchmarks: test doubles

**Estado:** draft

No hay benchmark propio. Este capítulo clasifica decisiones pedagógicas y
medirlas no representa el costo de mantener un fake o de diagnosticar un mock.
Un benchmark artificial ocultaría la pregunta útil: cuánto cuesta mantener el
doble alineado con su contrato real.

El repositorio ejecuta `cargo bench --all-targets` como verificación de ruta.
