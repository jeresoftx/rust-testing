# Introducción

`rust-testing` es el curso complementario de Jeresoft Academy dedicado a
testing como disciplina de diseño.

El curso parte de una idea sencilla: una prueba no es una ceremonia para subir
porcentaje de cobertura. Una prueba es una forma de hacer explícito qué debe
seguir siendo cierto cuando el sistema cambia.

## Frontera del curso

Este repositorio enseña:

- cómo razonar sobre confianza, riesgo y observabilidad;
- cómo escribir pruebas unitarias y de integración en Rust;
- cómo usar dobles de prueba sin esconder mal diseño;
- cómo pensar en propiedades, contratos, mutantes, rendimiento y caos;
- cómo combinar pruebas con revisión humana y operación real.

Este repositorio no enseña una receta de un framework específico. Las
herramientas concretas aparecerán cuando aporten valor, pero el curso se ancla
en fundamentos que siguen siendo útiles aunque las herramientas cambien.
