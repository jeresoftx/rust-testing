# Ejercicios: performance testing

**Estado:** draft

## Nivel 1: definir medición

Declara escenario, unidad y presupuesto para serializar un pedido, crear una
factura y consultar un catálogo.

```bash
cargo run --example performance_testing_nivel_1
```

## Nivel 2: interpretar resultado

Distingue una regresión de una medición inconclusa por ruido o sin referencia.

```bash
cargo run --example performance_testing_nivel_2
```

## Nivel 3: evitar conclusiones indebidas

Explica por qué un resultado local dentro de presupuesto no demuestra capacidad
de producción y qué métrica adicional necesitarías.

```bash
cargo run --example performance_testing_nivel_3
```
